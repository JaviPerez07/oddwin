# Proposed uses — shared annex for all requests

Attach or paste into each request. Keep it identical across providers so permissions can be compared.

| Asset | Where it appears | Treatment |
| --- | --- | --- |
| Key art / game banner | Header of the editorial review page for that game; homepage "featured review" | Resized only; displayed uncropped unless you allow cropping to our layout (16:9) |
| Catalogue thumbnail / game tile | Game catalogue and lists of related games | Resized only |
| Game logo | Review page header (optional) | Unaltered, on a dark neutral background |
| In-game screenshots | Inside the review, illustrating mechanics or bonus rounds | Unaltered, captioned |
| Studio logo | Our page about your studio | Unaltered, per your brand guidelines |

- **Context:** independent editorial reviews and a game catalogue. Some pages may include clearly labelled affiliate links to licensed operators, kept separate from the editorial analysis.
- **Territory:** international website. We restrict commercial listings by market and follow applicable advertising rules; images would be visible worldwide.
- **Credit:** we will display the credit line you specify next to every image.
- **No AI alteration, no merchandise, no use in paid ads** unless you allow it separately.
- **Withdrawal:** we can remove any asset within 48 hours of a request (assets are switched off centrally in our asset register).
